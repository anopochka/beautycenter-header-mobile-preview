## For the developer

`index.html` contains the complete preview layout, inline CSS and JavaScript for the mobile header, scrolling and menu interactions. Open it in a browser; no build or installation is required.

Images, icons and fonts are loaded from the original preview's public assets URL and require an internet connection. This repository is a visual and interaction reference, not a production CMS implementation.
